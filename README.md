# 🚀 Personal Portfolio Website

A modern, responsive developer portfolio built with **HTML, CSS, and Three.js** featuring interactive 3D visuals and smooth animations.

---

## 🌐 Live Demo

👉 https://blazer35.github.io/
---

## ✨ Features

* ⚡ Fully responsive design (mobile + desktop)
* 🎨 Modern UI with glassmorphism styling
* 🌌 Interactive **Three.js** particle background
* 🧠 Smooth scroll + reveal animations
* 📱 Optimized for performance

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Three.js

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Open in VS Code

```bash
code .
```

### 3. Run the project

* Install **Live Server** extension in VS Code
* Right-click `index.html`
* Click **"Open with Live Server"**

---

## 🎨 Customization Guide

### 👤 Change your name

Edit in `index.html`:

```html
<h1 class="hero-name">Your Name</h1>
```

### 💼 Update experience & projects

Modify sections inside `index.html`

### 🎨 Change colors

Edit variables in `style.css`:

```css
:root {
  --accent: #00f5c4;
}
```

---

## 📱 Mobile Fix (Important)

If text gets cut on small screens, adjust:

```css
.hero-name {
  line-height: 1.1;
}
```

---

## 🚀 Deployment (GitHub Pages)

1. Push your code:

```bash
git add .
git commit -m "Initial commit"
git push
```

2. Go to:
   Settings → Pages → Select branch `main`

3. Your site will be live at:

```
https://your-username.github.io/
```
